**Um aplicativo para calcular o IMC do usuário.** 

- A primeira tela deve permitir a entrada do peso eum aplicativo para calcular o IMC do usuário. 
- A segunda tela exibirá o IMC do usuário e uma mensagem informando se ele está abaixo:
    1. abaixo do peso;
    2. com peso ideal;
    3. com sobrepeso;
    4. ou com obesidade.
